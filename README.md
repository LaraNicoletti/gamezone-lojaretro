Projeto prático de LIMA que aplica os fundamentos do HTML aprendidos em sala: uso de títulos, listas, imagens, links e tabelas na estruturação de uma página.

# 🎯 Objetivo
Consolidar o aprendizado prático de desenvolvimento web front-end através da criação de uma página HTML completa, aplicando conceitos essenciais de estruturação de conteúdo, hierarquia de texto, exibição de mídias, tabelas e links de navegação.
